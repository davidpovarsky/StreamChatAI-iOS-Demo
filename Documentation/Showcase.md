# Showcase UI Lab

The Showcase app (`Showcase/`) is an in-repo reference application that demonstrates all AgentUI SDK capabilities.

## Features

- **Package Consumed**: Imports `AgentUI` and `AgentUIShowcaseSupport` exactly like external apps.
- **Mock Runtime**: Realistic deterministic streaming simulator with cancellation and retries.
- **Zero Configuration**: No API keys, credentials, or network connection required.
- **Comprehensive Scenarios**: Chat basics, code with copy, math, Hebrew RTL, citations, ChatGPT-style activity timelines, one-surface tool disclosures, and interactive mini apps.
